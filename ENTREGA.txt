4. INSTRUCCIONES DE DESPLIEGUE LOCAL RÁPIDO (DOCKER)
------------------------------------------------------------------------
Si desea levantar la aplicación localmente en un entorno aislado (HTTP Puerto 80):
1. Clonar el repositorio: git clone https://github.com/Naleper90/Kinefy.git
2. Acceder al directorio: cd Kinefy
3. Iniciar el entorno orquestado con Docker Desktop activo:
   docker compose up --build -d
4. Acceder en el navegador a: http://localhost
5. (Opcional) Para poblar la base de datos de producción/pruebas:
   docker exec -it kinefy-api npm run seed:prod
